最終六人協作驗收

最後的驗收，不是看完影片。

每位組員：Clone 團隊 Repo → 建立個人分支 → 只改自己的資料夾 → Commit → Push → 建立 PR。由帶領者審核後合併；大家再 Pull 最新 main，確認六份文件都在。

提示：資料夾不是分支；每一條 Git 分支仍含整個專案。實際分支圖會依操作與 Merge 策略而不同，此處為教學示意。
