Git × 小烏龜 × GitHub — 28 步協作操作分享

1. 直接雙擊 index.html，即可用瀏覽器開啟。
2. 左側選取操作步驟；手機可使用頂部下拉選單。
3. 每一步包含操作順序、關鍵畫面、前後狀態圖與結果確認。
4. 勾選的完成進度會儲存在此瀏覽器 localStorage（若為無痕模式可能不保留）。
5. 圖片已放在 assets 資料夾；分享時請把 index.html、README.txt 與整個 assets 資料夾一起傳送。
6. 本 HTML 不會讀取本機 Git、執行命令或登入 GitHub。版本線圖是操作說明，不會改動 Repository。

主線：從本機初始化、Commit、分支與 Merge，接 GitHub 同步、指定一位審查者的 PR 流程，最後查看 Network 分支合併線圖。
