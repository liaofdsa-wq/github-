Git × 小烏龜 × GitHub — 27 步互動圖解教學

1. 直接雙擊 index.html，即可用瀏覽器開啟。
2. 左側選取教學步驟；手機可使用頂部下拉選單。
3. 每關有操作前後圖、文字步驟、影片預留位置、驗收勾選。
4. 勾選的完成進度會儲存在此瀏覽器 localStorage（若為無痕模式可能不保留）。
5. 未放影片時顯示預留框。請建立 videos 資料夾並依照每關顯示的英文檔名放入 MP4，即可直接播放。
6. 本 HTML 完全不會讀取本機 Git、執行命令或登入 GitHub。所有版本圖都是教學示意，非真實 Repository 狀態。

主線：從本機初始化 Git、Commit、分支與 Merge，接 GitHub 推送、PR 審核，再由六人各自在獨立資料夾完成實作。
