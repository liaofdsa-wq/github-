此圖的 Commit 是同一份 Git 歷史；本機／遠端區分的是「分支指標」位置。
本機與 GitHub 不一定同步

Commit 只增加本機版本；Push 才可能更新 GitHub 遠端分支；PR 只是提出合併申請，並不等於已合併。

遠端資訊可能不是最新

HTML 讀取的是本機儲存的 origin/*。按「Fetch」更新遠端追蹤資訊，再刷新圖，才能與最新 GitHub 狀態比較。

預覽是推估，不是保證

Commit 的新 SHA、Push 網路權限、Pull 是否快轉，以及 PR 是否能合併，執行前都無法完全確定。這些會明確標示為預覽。

只接受預定義操作：建立／切換分支、Commit、Push、Fetch、Pull，或開啟 GitHub PR 網頁。不接受任意 CMD 指令。所有修改需再次確認；按刷新只讀本機資訊。請勿將本機服務公開到網路。
